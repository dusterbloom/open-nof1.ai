## 💡 Key Insights & Learnings

### Technical
1. **Lightweight Charts v5 API**: `createSeriesMarkers()` is a standalone function, not a method
2. **Data Resolution Matters**: 1000 points vs 50 points = night and day difference in smoothness
3. **Liquidation Math**: Higher leverage = exponentially higher risk (20x = 4.5% to liquidation)
4. **Safety Buffers**: 10% threshold provides good balance of safety vs premature closes

### Architecture
1. **Safety First**: Checks run BEFORE AI decision (hard cutoff)
2. **Separation of Concerns**: Liquidation calc in wallet, integration in account info, protection in run loop
3. **Transparency**: All emergency actions logged with full context
4. **Testability**: Pure calculation functions enable easy unit testing
